## ⚠️ Aviso importante

Este repositorio tiene **fines exclusivamente educativos**. Aquí replico, paso a paso, lo que se enseña en el video para **aprender y fortalecer mis habilidades** como desarrollador.

- 🎥 **Video original:** [Aprende Desarrollo Full-Stack desde Cero - Tutorial para Novatos a Avanzado](https://www.youtube.com/watch?v=mXpWhmJXV0o)
- 👤 **Autor:** [midudev](https://www.youtube.com/@midudev)
- 🙌 **Todo el contenido, las ideas y el material del curso pertenecen a midudev.** Yo solo escribo el código mientras sigo el tutorial, como ejercicio de aprendizaje.
- 🚫 **No es un proyecto oficial** ni tiene relación con midudev, y **no tiene fines comerciales**.

Si eres el autor y quieres que modifique o retire este repositorio, escríbeme abriendo un *issue* y lo atiendo de inmediato.

## 🎯 Objetivo

Aprender desarrollo **full-stack** de principio a fin replicando el proyecto del video. Lo que aprenda aquí lo aplicaré después en mis propios proyectos.
